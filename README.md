# Семинар: «Білім сапасын арттыру»

Ұлытау облысы, Жезқазған қаласының математика пәні мұғалімдеріне арналған семинардың беті.
**29 қазан 2026, 10:00 · №8 гимназия, акт залы**

Мұғалім QR-кодты сканерлейді → тізімнен өз атын табады → «Иә, келдім» басады.
Белгі Google кестеге түседі (3-қадам) және/немесе WhatsApp арқылы ұйымдастырушыға жіберіледі.

## Файлдар

| Файл | Не үшін |
|---|---|
| `index.html` | Семинардың негізгі беті (лендинг + «Келдім» белгілеу) |
| `qr.html` | Басып шығаруға арналған үлкен QR-код |
| `config.js` | Баптаулар: WhatsApp нөмірі, Google кесте сілтемесі |
| `teachers.js` | Мұғалімдер тізімі (78 адам) |
| `apps-script/Code.gs` | Google кестеге жазатын скрипт |

## 1-қадам. GitHub-қа салу

1. github.com сайтында жаңа репозиторий ашыңыз (`zhez-seminar`), **Public** етіп.
2. **Add file → Upload files** арқылы осы бумадағы барлық файлдарды (буманың ішіндегі `apps-script` бумасымен бірге) жүктеңіз → **Commit changes**.

## 2-қадам. GitHub Pages қосу

1. Репозиторийде **Settings → Pages**.
2. **Source: Deploy from a branch**, **Branch: `main`**, бума **`/ (root)`** → **Save**.
3. 1–2 минуттан кейін бет мына мекенжайда ашылады:
   https://yera-atoc.github.io/zhez-seminar/
4. QR-код: https://yera-atoc.github.io/zhez-seminar/qr.html — басып шығарыңыз немесе экранға шығарыңыз.

## 3-қадам. «Келдім» белгілерін Google кестеге жинау (ұсынылады)

1. Google Drive-та жаңа **Google Sheets** кестесін ашыңыз.
2. **Кеңейтімдер (Extensions) → Apps Script**.
3. Ашылған редактордағы кодты өшіріп, `apps-script/Code.gs` файлының мазмұнын қойыңыз → **Сақтау**.
4. **Deploy → New deployment** → түрі **Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
   → **Deploy**, рұқсат беріңіз.
5. Берілген **Web app URL** сілтемесін (`https://script.google.com/macros/s/.../exec`) көшіріңіз.
6. `config.js` файлында `sheetUrl: "..."` жолына осы сілтемені қойыңыз және GitHub-та сақтаңыз.

Енді әр «Келдім» белгісі кестенің **«Келгендер»** парағына уақытымен бірге түседі. Бір адам екі рет басса, қайталанбайды.

## 4-қадам (қажет болса). WhatsApp

`config.js` ішінде `whatsapp: "77011234567"` деп нөміріңізді жазыңыз — сонда «WhatsApp арқылы жіберу» батырмасы шығады.

## Тізімді өзгерту

`teachers.js` файлын GitHub-та ашып, қарындаш белгісін басыңыз. Жаңа жол қосу:

```js
  {"id": "new001", "name": "Тегі Аты Әкесінің аты"},
```

`id` — кез келген қайталанбайтын сөз. Тізімде жоқ адамдар беттегі «Тізімде жоқпын» батырмасы арқылы белгілене алады.
